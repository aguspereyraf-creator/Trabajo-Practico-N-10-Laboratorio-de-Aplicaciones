## Prolog vs Python

La diferencia entre estos dos es que Prolog Utiliza hechos y reglas, las reglas son mas cortas, busca soluciones automaticamente y es sencillo agregar nuevas reglas.
Mientras que python utiliza diccionarios y funciones, se necesitan mas lineas de codigo, hay que indicar como realizar la busqueda y se deben crear o modificar funciones.

Se utilizó ChatGPT como asistente para comprender conceptos de Prolog y Python, resolver dudas y revisar el código. El código fue probado antes de ser utilizado
